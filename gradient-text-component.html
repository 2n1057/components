Gradient Text <GradientText />

Envolve qualquer trecho de texto (ou elemento, via as) em quatro manchas de cor borradas que se deformam e vagueiam por trás dele em loop, recortadas pelo próprio contorno do texto com overflow-hidden + mix-blend-lighten/darken. Sem canvas, sem SVG — só Tailwind, keyframes e Motion.

React TypeScript Tailwind CSS Motion (framer-motion)

Design without Limits

preview ao vivo · looping automático gradient-border: 6s · gradient-1..4: 12s alternate

Código do componente

Copie e cole em /components/ui/gradient-text.tsx.

components/ui/gradient-text.tsx 
"use client"
import React from "react";
import { motion, type MotionProps } from "motion/react";

import { cn } from "@/lib/utils";

interface GradientTextProps
  extends Omit<React.HTMLAttributes<HTMLElement>, keyof MotionProps> {
  className?: string;
  children: React.ReactNode;
  as?: React.ElementType;
}

function GradientText({
  className,
  children,
  as: Component = "span",
  ...props
}: GradientTextProps) {
  const MotionComponent = motion.create(Component);

  return (
    <MotionComponent
      className={cn(
        "relative inline-flex overflow-hidden bg-white dark:bg-black",
        className,
      )}
      {...props}
    >
      {children}
      <span className="pointer-events-none absolute inset-0 mix-blend-lighten dark:mix-blend-darken">
        <span className="pointer-events-none absolute -top-1/2 h-[30vw] w-[30vw] animate-[gradient-border_6s_ease-in-out_infinite,gradient-1_12s_ease-in-out_infinite_alternate] bg-[hsl(var(--color-1))] mix-blend-overlay blur-[1rem]"></span>
        <span className="pointer-events-none absolute right-0 top-0 h-[30vw] w-[30vw] animate-[gradient-border_6s_ease-in-out_infinite,gradient-2_12s_ease-in-out_infinite_alternate] bg-[hsl(var(--color-2))] mix-blend-overlay blur-[1rem]"></span>
        <span className="pointer-events-none absolute bottom-0 left-0 h-[30vw] w-[30vw] animate-[gradient-border_6s_ease-in-out_infinite,gradient-3_12s_ease-in-out_infinite_alternate] bg-[hsl(var(--color-3))] mix-blend-overlay blur-[1rem]"></span>
        <span className="pointer-events-none absolute -bottom-1/2 right-0 h-[30vw] w-[30vw] animate-[gradient-border_6s_ease-in-out_infinite,gradient-4_12s_ease-in-out_infinite_alternate] bg-[hsl(var(--color-4))] mix-blend-overlay blur-[1rem]"></span>
      </span>
    </MotionComponent>
  );
}

export { GradientText }

Pré-requisitos do projeto

Assume um projeto shadcn/ui já configurado com Tailwind CSS e TypeScript. Se ainda não tiver:

setup — terminal 
# criar projeto (se ainda não existir)
npx create-next-app@latest meu-app --typescript --tailwind --eslint

# dentro do projeto: iniciar shadcn/ui
npx shadcn@latest init

# biblioteca de animação usada pelo componente
npm install motion

# isso cria automaticamente components.json e a pasta
# components/ui — que é o local padrão esperado
Se o caminho padrão de componentes do seu projeto não for /components/ui, crie essa pasta manualmente: é o local convencionado pelo shadcn/ui para primitivos reutilizáveis, e manter esse padrão evita que o CLI e outros componentes gerados percam a referência de import (@/components/ui/...).

Passos de integração

Colar o arquivo

Salve o código em components/ui/gradient-text.tsx. Ele depende de cn vindo de @/lib/utils — confirme que esse helper já existe no projeto (o CLI do shadcn o cria por padrão).

Dependência externa

Instale motion (sucessor do framer-motion). O componente usa motion.create(Component) para tornar qualquer tag animável mantendo o tipo genérico via as.

Tailwind + CSS globais

Sem estender o tailwind.config.js (seção 3) e o globals.css (seção 4), as classes animate-[gradient-border_...] e bg-[hsl(var(--color-N))] não resolvem para nada — o texto renderiza sem nenhuma mancha de cor.

"use client"

Usa motion, que roda no cliente. Mantenha a diretiva "use client" no topo do arquivo se o projeto usa Next.js App Router.

Onde usar

Feito para destacar uma palavra ou frase curta dentro de um título grande (hero, seção de features, CTA) — evite aplicar em blocos de parágrafo, o efeito perde legibilidade em texto pequeno.

7

Notas técnicas

  • O recorte da mancha de cor no formato exato das letras vem do overflow-hidden no elemento raiz — as 4 manchas são maiores que o texto (30vw) e ficam cortadas pela caixa do próprio elemento.
  • mix-blend-lighten (claro) / mix-blend-darken (escuro) no wrapper interno decide como a cor se funde com o fundo (bg-white/bg-black) atrás do texto; mix-blend-overlay em cada mancha decide como elas se misturam entre si.
  • Cada mancha anima duas propriedades em paralelo: gradient-border (deforma o border-radius a cada 6s) e gradient-N (desloca a posição a cada 12s, alternando). O resultado nunca se repete de forma óbvia.
  • Como as aceita qualquer ElementType, dá pra usar em <a>, <h2>, <button> etc. sem perder a tipagem de atributos daquele elemento.
  • Sem imagens externas nem SVG — só blur-[1rem], gradiente HSL via variáveis CSS e os keyframes do Tailwind.
