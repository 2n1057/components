Message Loading <MessageLoading />

Indicador de "digitando..." animado em SVG puro, três pontos com bounce sequencial. Sem dependências externas além do React.

React TypeScript SVG animado Tailwind (cor via classe)
preview ao vivo · animação SMIL

Código do componente

Copie e cole em /components/ui/message-loading.tsx

components/ui/message-loading.tsx 
function MessageLoading() {
  return (
    <svg
      width="24"
      height="24"
      viewBox="0 0 24 24"
      xmlns="http://www.w3.org/2000/svg"
      className="text-foreground"
    >
      <circle cx="4" cy="12" r="2" fill="currentColor">
        <animate
          id="spinner_qFRN"
          begin="0;spinner_OcgL.end+0.25s"
          attributeName="cy"
          calcMode="spline"
          dur="0.6s"
          values="12;6;12"
          keySplines=".33,.66,.66,1;.33,0,.66,.33"
        />
      </circle>
      <circle cx="12" cy="12" r="2" fill="currentColor">
        <animate
          begin="spinner_qFRN.begin+0.1s"
          attributeName="cy"
          calcMode="spline"
          dur="0.6s"
          values="12;6;12"
          keySplines=".33,.66,.66,1;.33,0,.66,.33"
        />
      </circle>
      <circle cx="20" cy="12" r="2" fill="currentColor">
        <animate
          id="spinner_OcgL"
          begin="spinner_qFRN.begin+0.2s"
          attributeName="cy"
          calcMode="spline"
          dur="0.6s"
          values="12;6;12"
          keySplines=".33,.66,.66,1;.33,0,.66,.33"
        />
      </circle>
    </svg>
  );
}
export { MessageLoading };

Pré-requisitos do projeto

Este componente assume um projeto shadcn/ui já configurado com Tailwind CSS e TypeScript. Se ainda não tiver:

setup — terminal 
# criar projeto (se ainda não existir)
npx create-next-app@latest meu-app --typescript --tailwind --eslint

# dentro do projeto: iniciar shadcn/ui
npx shadcn@latest init

# isso cria automaticamente components.json e a pasta
# components/ui — que é o local padrão esperado
Se o caminho padrão de componentes do seu projeto não for /components/ui, crie essa pasta manualmente: é o local convencionado pelo shadcn/ui para primitivos reutilizáveis, e manter esse padrão evita que o CLI e outros componentes gerados percam a referência de import (@/components/ui/...).

Passos de integração

Colar o arquivo

Salve o código acima em components/ui/message-loading.tsx.

Dependências externas

Nenhuma. O componente usa apenas SVG nativo com animação SMIL (<animate>) — não depende de framer-motion, lucide-react ou qualquer lib de ícones.

Cor / tema

A classe text-foreground herda a cor do texto do tema Tailwind/shadcn. Troque por qualquer classe de cor utilitária (ex: text-primary, text-muted-foreground) conforme o contexto onde for usado.

Onde usar

Ideal como indicador de "digitando..." em interfaces de chat, dentro de uma bolha de mensagem, ao lado de um avatar, ou em qualquer estado de carregamento assíncrono compacto.

4

Notas técnicas

  • Componente sem props — puramente visual e sem estado interno em React (a animação roda via SMIL/SVG nativo do navegador).
  • Sem imagens ou assets externos necessários.
  • Responsivo por natureza: ajuste width/height do SVG ou envolva em um container com className de tamanho.
  • Os IDs spinner_qFRN e spinner_OcgL encadeiam o timing entre os três pontos — não duplique esse componente múltiplas vezes na mesma árvore DOM sem considerar colisão de IDs se for renderizar via dangerouslySetInnerHTML (via JSX normal não há problema).
